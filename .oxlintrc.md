# Why these rules are off

`.oxlintrc.json` cannot carry comments, so the reasoning lives here.

- **`no-await-in-loop`** — the HTTP client's retry loop and the routing
  provider's host fallback must run one attempt after another. Parallelising
  them would defeat the backoff entirely and send *more* traffic to free public
  services, which is the opposite of what this project is trying to do.
- **`no-new`** — `new Notification(...)` is how the browser notification API is
  used. There is no result to assign.
- **`unicorn/no-array-sort`, `unicorn/no-array-reverse`** — every call site
  copies the array with a spread first, so nothing is mutated. The
  non-mutating `toSorted`/`toReversed` are ES2023 and this project targets
  ES2022.
- **`unicorn/consistent-function-scoping`** — two small maths helpers defined
  inside the function that uses them. Hoisting them buys nothing and reads
  worse.
